title: 1. Hugo installeren
---

Er zijn [heel veel manieren](https://gohugo.io/getting-started/installing/) om Hugo te installeren. Het mooie aan Hugo is dat installeren heel simpel is/kan zijn. Het komt eigenlijk allemaal op hetzelfde neer:

Op Windows download je de Windows-versie (tar.gz), pak je hem uit in je projectmap en start je 'hugo server' vanaf de command line. Op een Mac download je de MacOS-versie (tar.gz), pak je hem uit in je projectmap en start je 'hugo server' vanaf de command line. Op een Linux-machine installeer je Hugo door 'sudo apt install hugo' te typen. Ga daarna naar je projectmap en start 'hugo server' vanaf de command line. Wil je de nieuwste versie, dan kun je het .deb-bestand downloaden en met hetzelfde commando installeren (vervang 'hugo' door de naam van je .deb-bestand).
