### Introducción

El chat en vivo es una de las funcionalidades más importantes que puede ofrecer un sitio web. Esta solución de chat en vivo debería ser gratuita o freemium y debería ser muy sencillo para los visitantes iniciar una conversación en tiempo real. Además debería ser fácil de operar, gestionar y personalizar, y debería tener una aplicación móvil para el operador. He encontrado todo esto en [Crisp](https://crisp.chat/en/livechat/), gracias a una amplia investigación de [Appernetic](https://blog.appernetic.io/2016/07/14/use-live-chat-to-beat-the-competition/).

### Cómo funciona

Creas una cuenta en Crisp y añades un script en el head o en el pie de tu sitio web. El script inserta el módulo de chat en el sitio web. Eso es todo. Abajo se muestra un script de ejemplo. Deberías obtener tu código personal desde tu cuenta de Crisp.

[expand]

```
<script type="text/javascript">window.$crisp=[];window.CRISP_WEBSITE_ID="08f726ab-0303-4a41-9563-b9a32526b8ea";(function(){d=document;s=d.createElement("script");s.src="https://client.crisp.chat/l.js";s.async=1;d.getElementsByTagName("head")[0].appendChild(s);})();</script>
```

[/expand]

### Instalación

Paso 1. Crea una cuenta en [Crisp](http://crisp.chat) y configúrala
<br />Paso 2. Inserta el código HTML de Crisp en el head o en el pie de tu sitio web
<br />Paso 3. Descarga la aplicación gratuita de Android o iOS para una experiencia de chat sin interrupciones
